# WhatsApp AI Restaurant Chatbot

AI-powered WhatsApp chatbot built with n8n, Google Gemini, 
and WhatsApp Business API.

## Demo
[Watch Demo](https://youtu.be/roeeaey5mo0)

## Features
- Menu queries via AI
- Automated order taking
- FAQ handling
- Google Sheets order logging

## Tech Stack
- n8n (Workflow Automation)
- WhatsApp Business API
- Google Gemini AI
- Google Sheets
